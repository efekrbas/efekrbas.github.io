# Efe Kırbaş - Tool Portfolio

A curated collection of digital tools and utilities for developers, gamers, and Discord power users. Built with a modern, high-performance tech stack focusing on seamless user experiences.

## 🚀 Featured Tools

- **[Discord Badge Manager](https://efekrbas.github.io/discord-badge-manager)**: Easily manage and preview your Discord profile badges.
- **[Discord DM Cleaner](https://github.com/efekrbas/discord-dm-cleaner)**: A modern, user-friendly GUI tool to clean your Discord Direct Messages.
- **[Guns.lol Username Checker](https://github.com/efekrbas/guns.lol-username-checker)**: Find unclaimed guns.lol usernames efficiently.
- **[clicord](https://github.com/efekrbas/clicord)**: Use Discord directly inside your terminal. A powerful CLI built for developers.
- **[GitHub Unfollowers](https://github.com/efekrbas/GitHubUnfollowers)**: A lightweight script to quickly discover who unfollowed you on GitHub.

## 💻 Tech Stack

This portfolio is built using bleeding-edge web technologies to ensure maximum speed and optimal developer experience:

- **[Vite](https://vitejs.dev/)**: Next-generation frontend tooling.
- **[React](https://reactjs.org/)**: A JavaScript library for building user interfaces.
- **[TanStack Router](https://tanstack.com/router/latest)**: Type-safe, powerful routing for React applications.
- **[Tailwind CSS](https://tailwindcss.com/)**: A utility-first CSS framework for rapid UI development.

## 🛠️ Development

If you'd like to run this portfolio locally:

```sh
# Clone the repository
git clone https://github.com/efekrbas/efekrbas.github.io.git
cd efekrbas.github.io

# Install dependencies
npm install

# Start the development server
npm run dev
```
